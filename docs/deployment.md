# Server deployment

The Python server and its deployment instructions now live in [ssh-tunnel-switch](https://github.com/timlaing/ssh-tunnel-switch). Install the server from [PyPI](https://pypi.org/project/ssh-tunnel-switch/) and follow that repository for configuration and service management.

Start the server before OpenCode, then configure this plugin with its REST address and API token. See [plugin configuration](configuration.md) and the [package installation guide](../plugin/README.md).
